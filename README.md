# 🧠 Next Word Prediction using LSTM

A simple NLP application that predicts the **next word in a sentence** using an LSTM neural network.

### 🚀 Live Demo

https://next-word-prediction-lstmgit.streamlit.app/

### 🛠️ Technologies

* Python
* TensorFlow / Keras
* LSTM
* NLP
* Streamlit

### 📌 Example

```text
Input:  "what are you"
Output: "doing"
```

### ▶️ Run Locally

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```
